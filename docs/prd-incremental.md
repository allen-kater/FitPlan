# FitPlan 增量 PRD — V2 新功能

> 文档版本：v2.0 | 日期：2026-05-24 | 增量类型：功能追加

---

## 一、需求概述

在 FitPlan V1 基础上，追加 3 个功能模块：

| # | 功能模块 | 一句话描述 | 优先级 |
|---|---------|-----------|--------|
| 1 | 社区交流模块 | 健身爱好者发帖交流、打卡、互动的社区 | P1 |
| 2 | 拉伸图谱 + 关节活动图谱 | 上身/下身拉伸图示 + 关节-肌肉对应图谱 | P1 |
| 3 | 训练计划详情优化 | 按Excel原表格式展示部位/组数/关节活动/握法 | P0 |

### 2.3 UI / 交互描述

#### 社区首页 `/community`
- 顶部：页面标题"健身社区" + 发帖按钮（需登录，未登录点击跳转登录）
- 筛选栏：标签筛选（全部/健身打卡/训练心得/饮食分享/问题求助/经验交流）+ 排序切换（最新/热门）
- 帖子列表：卡片式 Feed 流
  - 卡片内容：作者头像(32px)+用户名+发布时间、分类标签(Chip)、标题(加粗)、正文摘要(2行截断)、底部：点赞图标+数、评论图标+数
  - 点击卡片进入帖子详情
- 右侧边栏（桌面端）：
  - 打卡排行榜卡片：周榜/月榜Tab，显示 Top5 用户头像+用户名+打卡天数

#### 发帖页 `/community/post`
- 标题输入（必填，最多50字）
- 正文输入（多行文本框，支持基本Markdown或纯文本，最多2000字）
- 分类选择（单选Chip组：健身打卡/训练心得/饮食分享/问题求助/经验交流）
- 提交按钮

#### 帖子详情页 `/community/:id`
- 帖子完整内容：标题、作者信息、发布时间、分类标签、正文
- 互动栏：点赞按钮(含数)、收藏按钮
- 评论区：
  - 评论输入框（登录用户）
  - 评论列表：用户名+时间+内容，按时间倒序

### 2.4 数据需求

新增数据库模型：

**Post（帖子）**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (UUID) | 主键 |

| commentCount | Int | 评论数（冗余计数） |

| userId | String | 外键 → User.id |
| createdAt | DateTime | 创建时间 |
| | | 联合唯一：postId + userId |

**PostFavorite（收藏）**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String (UUID) | 主键 |
| postId | String | 外键 → Post.id |
| userId | String | 外键 → User.id |
| createdAt | DateTime | 创建时间 |
| | | 联合唯一：postId + userId |

新增 API：
- GET /api/community/posts — 帖子列表（分页、排序、分类筛选）
- GET /api/community/posts/:id — 帖子详情（含评论列表）
- POST /api/community/posts — 发布帖子（需登录）
- POST /api/community/posts/:id/comments — 发表评论（需登录）
- POST /api/community/posts/:id/like — 点赞/取消点赞（需登录）
- POST /api/community/posts/:id/favorite — 收藏/取消收藏（需登录）
- GET /api/community/rankings — 打卡排行榜

- A表数据：每行 = {joint, movement, description, example, muscles: string[]}
- B表数据：按肌肉群分组，每行 = {joint, movement, description, muscleActions: Record<muscle, string>}

不需要新增数据库模型（数据量小且固定，前端JSON即可）。新增 API：
- GET /api/knowledge/stretch — 返回拉伸图片列表（含元数据）
- GET /api/knowledge/joint-activity — 返回A表+B表结构化数据
- GET /api/knowledge/joint-images — 返回图示版图片列表

## 六、待确认问题

1. **拉伸图片提取**：Excel 中的图片是嵌入式的，openpyxl 可以提取但图片标题/说明只有一行版权声明，没有每张图的具体标题。需要手动为每张图命名（如"胸大肌拉伸1"、"背阔肌拉伸2"等），或者用图片在 Excel 中的位置来推断。建议：先提取图片，人工审核命名。
